# Glossary — Cancer Transcriptomics Teaching Suite

Project-specific vocabulary: sample identifiers, assay names, cohort labels,
abbreviations that appear in column headers. The test for including a term is
whether a competent outsider would guess wrong.

Keep it alphabetical. One line each. Link a term to the file that defines it
where one exists.
