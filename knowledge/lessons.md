# lessons.md — Cancer Transcriptomics Teaching Suite

Rules written after corrections, so the same mistake is not repeated. Reviewed at the start of every session on this project.

## 2026-09-26

- **Cohort choice: immune cells first.** Do not default to TCGA solid tumours when proposing cancer datasets. Order of preference here is innate immune cells (neutrophils, monocytes) → other immune cells → solid tumours with large cancer and healthy groups. TCGA is Step-3, processed counts only.
- **Integration is in scope by default.** Transcriptomics plans for this project include the RNA→protein question (matched proteomics, translation as the missing layer) and non-coding RNA nuances (library type, lncRNA filters, miRNA-seq) from the first draft, not as later additions.
- **Verify accessions before proposing them.** Dataset candidates go into the plan only with a "verify" column; accessions asserted from memory were replaced by searched ones (E-MTAB-11190, Cassetta 2019). ENA/BioStudies pages are not searchable from the sandbox, so FASTQ availability checks are handed to Rytis with an exact query.
- **A citation in the plan is an accession too.** The plan named "Caronni et al. 2023 Nature" as the Step-1 source from memory; PubMed shows Montaldo et al. 2022 Nat Immunol (Caronni is a co-author). The ENA Portal API and BioStudies file listings are reachable from the sandbox after all (2026-09-27), so study metadata can be verified here; only the browser pages were not.
- **Document edits are targeted replacements with grep verification**, applied through one scripted pass with an exactly-one-match assertion per edit; no whole-file rewrites.
- **Check-ins use tappable decisions**, at most three per turn (two check-ins on 2026-09-29 asked four; hold to three), recommended default marked; everything else is stated as an assumption in the plan.
- **Open decisions are counted from the file, not from memory.** On 2026-09-26 "only D5 and D17 remain" was reported while D3 and D6–D9 had never been confirmed. Before stating what remains open, grep the decisions table for rows not marked Resolved or Superseded.
- **Prove a template update with a real one.** An update to the same template version is a no-op and cannot fail. Tag a synthetic release in a scratch clone that edits next to every project addition, and update a scratch project clone to it. Lines appended at the end of CLAUDE.md and AGENTS.md conflicted with the template's own appends; at the top of each file they merge.
- **Measure the finished figure file, not the code.** On macOS, pyplot's GUI backend made an 85 mm page 84.84 mm, and seaborn desaturated every box fill to 75 %. Both were invisible in the code and caught only by reading the PDF. Build figures with `matplotlib.figure.Figure`, pass `saturation=1`, and assert page size and painted colours.
- **Files built from the same coordinates cannot check each other.** A wrong rebase offset kept slice.fa, slice.gtf and transcripts.fa mutually consistent and passed every offline test. Anchor a fixture to external truth: its start codons must read ATG.
- **A pre-registered rule needs its content checked, not only its commit order.** A rule rewritten between the rule commit and the record commit passed an ancestry test. Compare the rule as first committed with the rule in force.
- **Eye-check a figure at its real size before accepting a style.** 14 pt text in an 85 mm column overlapped for 8 genes. The sizes stay, the layout adapts, and a test measures every text box for overlap.
- **Raw-read download is nf-core/fetchngs 1.12.0, not custom code.** The first plan proposed ENA API / `fastq-dl` download logic; Rytis replaced it with fetchngs. The suite consumes the fetchngs output layout through `ctx gather` alone and teaches accession discovery around it.
- **Read a pipeline's output layout from its code, not its docs.** The fetchngs docs list `*.runinfo.tsv` and untimestamped `pipeline_info` names that 1.12.0 does not publish, and md5 files exist only for FTP and Aspera downloads. Pin the layout with a real run of the pinned release, committed as a fixture.
- **Assert byte identity only on what a tool fixes.** A fetchngs rebuild reproduced every file except the row order of one `runinfo_ftp.tsv`; fetchngs does not fix that order. Check what the tool guarantees, compare the rest by content, and retry a network proof once before calling it failed: the first download rebuild stalled on NCBI and the retry passed.
- **A mutation harness must leave no bytecode.** Python trusts a `.pyc` whose recorded source mtime (whole seconds) and size match. A same-size mutation (`10` to `11`, `max` to `min`) restored within the second its test ran left the mutated bytecode in force: the restored code then failed its own test while the source read correctly. Run mutated tests with `PYTHONDONTWRITEBYTECODE=1`, delete `__pycache__` after restoring, and rerun any same-size mutation on a clean cache.
- **A test at real size finds what the fixture sizes hide.** At 60,000 genes the volcano page embedded every table row and reached 19.3 MB against a 15 MB cap, and a featured gene set of 3,000 genes was tested in no contrast, which left an empty bar figure. Neither showed at 1,000 genes. Run the budget test before calling an engine done.
- **Check interactive figures in the browser, in both themes.** Static-figure tests passed while the plotly volcano stacked its gene labels, its slider covered the caption, and a line drawn in the light theme's ink vanished in the dark one.
- **A line the reader moves must move with the control.** The volcano's cutoff line sat at the weakest passing gene's raw p, which changes only when a gene crosses the cutoff, so it stood still between cutoffs that call the same genes, and Rytis read it as broken. Draw the procedure's own bar, which is proportional to the cutoff and still separates (D-015).
- **A test that needs a gene in an edge zone must plant one.** `test_de_end_to_end` asserted that the significant count differs from the called count, which needs a gene significant at |log2 FC| < 1; with planted effects at 2.5 only a chance false positive supplied it, and a change to the generator's noise emptied the zone. The planted-FDP bound of 0.10 likewise passes at seed 7 by the draw: on the committed generator, 42 of seeds 0 to 199 exceed it (mean 0.079, max 0.171), and seed 7 gives 0.065.
- A number box's arrows step by `step` from its minimum, so `step="any"` over a log range (0.0001 to 0.1) went 0.05 to 0.0001 and then nowhere, and `list=` adds a bare ▼. A value that lives on a log scale steps through its presets in `ctxCalls.step`, tested by walking every rung under node (Rytis, 2026-09-29).
- A size in pt drawn in px needs its conversion written once and tested on numbers: `on_page` added 4 to a pt value and used it as px, so "3 pt larger" came out 0 pt larger for a day (D-024).
- A private helper needs a docstring too: `interrogate` holds `src/` at 100 % and failed preflight twice on 2026-09-30 for `_stratum_label` and `_value_title`. Run `pixi run python -m interrogate -vv src/ctx | grep MISSED` before preflight, and `ruff check` on new files before committing: `pixi run hooks` checks tracked files only.
- A Jinja attribute that names a dict method prints the method: `ui.reproduce.copy` put `<built-in method copy of dict object>` on every Copy button for a day, past a browser check that looked at layout, not words. Read a rebuilt page's buttons as text, and keep `ui.toml` keys off dict method names (`test_no_ui_key_shadows_a_dict_method`, D-033).
- fetchngs's downloads die on the first refused connection: its wget has `-t 5` but not `--retry-connrefused`, and 50 at once from Kebnekaise got 2 of 210 Step-1 FASTQs before the run ended (D-035). - Never nest a heredoc inside a heredoc with the same delimiter: an inner `<<'EOF'` in a Python edit script closed the outer one, and the remaining lines ran as shell on the Mac (2026-09-30; harmless only because `$P` was empty there). Write edit scripts to a file first.
